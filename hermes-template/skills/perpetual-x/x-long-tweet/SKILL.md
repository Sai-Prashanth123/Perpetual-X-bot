# Long tweet

Run the whole `content-pipeline`. Format B from the tweet SOP
(`agency-writing-standards/references/x-tweet-sop.md`, and the client's `references/x-tweets.md`):

- Over 280 characters (typically 600–1,500), reads as a **mini-essay**, not a thread crammed in.
- Opens on a **result-number hook** or a sharp contrarian line from their real experience.
- Flowing short paragraphs, not bullet soup (a short "→" list is fine if the client uses them).
- One idea. Ends forward-looking (what to do, what's next), never a summary or "thoughts?".
- No links in the body, no hashtags, no em dashes.

Save with `kind: "long_tweet"`.
